# 🏇 KEIBA ROYALE

歴代の名馬たちが走る、友達と遊べる競馬ベッティングゲーム！

ディープインパクト、オグリキャップ、サイレンススズカ……歴代の名馬40頭の中から毎レース8頭が出走。
仮想ポイントを賭けてレースを観戦しよう。

## 遊び方

1. **プレイヤー登録** — 1〜6人のメンバーを登録（各10,000ptスタート）
2. **馬券購入** — 出馬表とオッズを見て、単勝・複勝・馬連からベット
3. **レース観戦** — Canvasで描かれるリアル風レース映像を観戦🔥
4. **払い戻し** — 的中したら配当ゲット！残高は自動保存されて次のレースへ

## 機能

- 🐎 歴代名馬40頭からランダム出走（脚質: 逃げ/先行/差し/追込）
- 🎫 馬券3券種: 単勝 / 複勝 / 馬連 — リアルな馬券チケット風プレビューUI
- 📊 能力ベースのオッズ自動算出・勝率バー・人気バッジ（番狂わせもあり）
- 🎬 Canvas製レース映像: 疑似3Dレーン / ベジェ曲線の馬体 + 4拍ギャロップ / 観客スタンド / 芝の蹴り上げ / ラストスパートのズーム&ムチ / 写真判定フラッシュ / 紙吹雪 / 実況テロップ
- 💾 プレイヤー残高は localStorage に自動保存
- 📏 距離選択: 1200m〜3200m

## 開発

```bash
npm install
npm run dev
```

- Next.js 15 (App Router)
